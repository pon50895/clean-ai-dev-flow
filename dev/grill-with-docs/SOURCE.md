## 原版做什麼(摘要)

`grill-with-docs` 跑一場 grilling + domain-modeling:逼問式訪談的同時**主動建領域模型**——挑戰 / 釐清語言、對照 code 校準、決策定案就即時寫進 `CONTEXT.md`(純 glossary)/ ADR(只在難反轉 + 意外 + 真取捨時建);懶建檔。

## 我改了什麼

- 接上 GSD **Discuss** 與領域術語紀律;範例改為專案中性(金流狀態機 / schema / API 契約)。
