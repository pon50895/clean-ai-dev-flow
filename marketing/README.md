# marketing/ — 行銷 skill 收藏(改造自 coreyhaines31/marketingskills)

有機獲客為主的行銷 skill,繁中重寫,已去除特定產業寫死內容,定位與北極星指標由各專案的 product-marketing context 文件定義。付費廣告 / 大規模 / A-B 等段已砍(YAGNI)。出處見各資料夾 `SOURCE.md` 與根目錄 `SOURCES.md`。

| skill | 一句話 | 觸發時機 |
|---|---|---|
| `product-marketing` | 行銷定位 SSOT,其他行銷 skill 先讀它 | 開任何對外文案前 |
| `free-tools-growth` | 榨乾現有免費工具漏斗做獲客 | 想用工具引流 / 評估新工具 |
| `social-media` | FB/IG/Threads 貼文 / 短影音 / 內容日曆 | 寫社群文案 |
| `referral-programs` | 推薦迴圈設計 | 設計分享 / 推薦機制 |
| `de-ai-tone` | 中文去 AI 語感、改台灣人講話(含兩岸用語、標點 house style) | 對外文案定稿前 |

**共通紅線**:不製造恐懼逼購、不宣稱未發生的驗證、不寫死價錢、供應商保密(依專案政策)、台灣式去 AI 腔;每支收尾指向 `de-ai-tone` + 專案自己的 claim 逐條查證流程。

依賴順序:`product-marketing` 是基礎(產定位 context),其餘三支開工前先讀它產出的定位文件。
