# free-tools-growth — 免費工具獲客

改造自 coreyhaines31/marketingskills 的 `free-tools`(MIT license)。核心差異:本專案**已經蓋了一堆免費工具**,這支的重點不是「該不該蓋工具」,而是「把現有工具接成獲客迴圈 + 只在有明確缺口時才蓋新的」。原版評分表保留;付費廣告 / 大規模那段砍掉(YAGNI,pre-revenue 口碑期用不到)。

開工前先讀 `docs/strategy/PRODUCT_MARKETING_CONTEXT.md`(沒有先跑 `product-marketing`)。

## 本專案已有的免費工具(先盤點再說要蓋新的)

- 免費八字論X 漏斗(?ref 歸屬,已 live)
- 每日一牌 Canva 圖卡(病毒獲客,backlog)
- 占星曆(換座 / 逆行,免登入公開 `/astrology/calendar`,已 live)
- 金錢卦公開 showcase(擲幣 + 兩階段 + 免費 email)
- 占星合盤 / 行運雙圈盤(老師端工具)

**先問**:現有工具的獲客漏斗接好了嗎(入口曝光、?ref 歸屬、導向下一步)?通常補現有工具的轉換比蓋新工具槓桿高。

## 三個核心原則(命理版)

1. **解真問題**:工具本身要有用,不靠命理主產品也值得用一次(例:占星曆查換座 / 逆行)。
2. **鄰近主產品**:自然把人從「查一下」帶到「想看完整解讀 / 預約」。北極星=歸屬預約,不是工具使用數。
3. **一件事做好、低摩擦**:免登入能玩就免登入,email 才 gate 完整結果。

## 導流路徑(工具 → 產品)

- 工具給即時免費價值 → 露出「看完整解讀 / 個人化報告」→ email 領取 → 導向預約 / 付費解讀。
- **?ref 歸屬**已建,新工具一律帶歸屬參數,能追到是哪個工具 / 分享來的。
- 免費層永遠留一個「往下走」的鉤子,但**賦權非恐嚇**——不用「你命裡有大凶,解鎖才知道」這種恐懼式 gate。

## Lead capture(命理版分層)

| 做法 | 用在哪 |
|---|---|
| 完全免登入 | 純 SEO / 病毒(占星曆、每日一牌圖卡) |
| 部分 gate(免費看摘要,email 領完整) | 八字論X、金錢卦 showcase(現行) |
| email 領永久頁 | 免費報告領取(內容嚴格本人) |

最佳實踐:價值交換講清楚(「email 領你的完整命盤解讀」)、只要 email、先給 preview。**文案守紅線**:不寫死價錢、不宣稱未做過的驗證、供應商講「AI」。

| 自然通往主產品 | ___ |
| 建置可行(MVP 能收斂) | ___ |
| 維護負擔(反向計分) | ___ |
| 病毒 / 分享潛力 | ___ |

25+ 強候選 / 15-24 可考慮 / <15 重新想。**低於門檻就別蓋**——pre-revenue 期先把現有工具的漏斗榨乾。

## MVP 範圍(YAGNI)

只做核心功能 + 基本 email 收集。跳過:帳號系統、存結果、完美設計、每個 edge case。命理工具特別注意:排盤 parity(移除=下架不硬刪)、大資產丟 R2 不進 git。

## 收尾

工具的對外文案(landing、CTA、email)定稿前過 `de-ai-tone` + `journal-preflight-scan`。跟 `social-media`(把工具做成種子貼文)、`referral-programs`(工具本身當分享標的)串起來用。
