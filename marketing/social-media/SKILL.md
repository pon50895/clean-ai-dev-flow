# social-media — 社群內容

改造自 coreyhaines31/marketingskills 的 `social`(MIT license)。平台聚焦台灣常用的 **FB / IG / Threads**(原版的 LinkedIn/X/TikTok 換掉);砍掉 A-B 測試與大規模投放段(YAGNI)。開工前讀 `docs/strategy/PRODUCT_MARKETING_CONTEXT.md`(品牌語氣、customer language),沒有先跑 `product-marketing`。

## 開工前先問

目標(獲客 / 導流 / 品牌)、目標受眾、要發哪個平台、有沒有現成素材可再利用(建造日誌 / 報告 / 免費工具)。

## Hook — 第一行決定有沒有人往下看

命理語境的四類 hook,都守**賦權非恐嚇、去宿命論**:

- **好奇型**:「你以為的『個性不合』,命盤上其實是……」(不製造恐懼)
- **故事型**:真實情境開場,不喊「震驚」。
- **價值型**:「三個判斷你八字喜不喜歡水的方法」,直接給乾貨。
- **反直覺型**:「命盤不是判決書,是一份系統規格書」——把定位講成鉤子。

禁:恐嚇式(「不看會有大凶」)、宿命論斷言、AI 腔(「這篇會接住你」)。

## 內容支柱(3-5 個,對齊定位)

例:(1) 命理知識科普(去神秘化、講原理);(2) 建造日誌 / 產品思路(降維打擊,不推銷);(3) 免費工具導流(占星曆、每日一牌);(4) 客戶語言回應(把 customer language 變成貼文主題)。每篇歸到一個支柱,別亂發。

## 內容再利用(本專案已有素材)

- **建造日誌 → 社群三平台**:已有 `release-page` skill 一鍵產 FB/IG/Threads 文字 + 圖卡,優先用它。
- **報告洞見 → 貼文**:把八字 / 占星解讀的一個具體洞見拆成單篇(不洩個資、不宣稱療效)。
- **免費工具 → showcase 貼文**:占星曆換座、每日一牌抽卡當鉤子。

## 短影音腳本(IG Reels / Threads)

結構:痛點 → 一個具體解法 → 導流。前 3 秒定生死。命理短影音守紅線:不鐵口斷命、不碰財務 / 健康 / 生命的確定性斷言(reader 安全三層同標準)。

## 平台差異(台灣)

- **Threads**:短、對話感、可連發串。台灣口語,別官腔。
- **IG**:圖卡 + 短 caption,Reels 走短影音。
- **FB**:可長一點,社團導流。

## 對外文案紅線(每篇都套)

- 供應商一律「AI」,不點名模型 / 供應商。
- 不宣稱未發生的驗證 / 審核 / 保證;不寫死價錢。
- 台灣式、去中國用語、去 AI 腔(禁「接住 / 讀懂」、去對稱排比空洞金句)。
- 呼應 storytelling-frame 框架(`scratchpad/STORYTELLING_框架.md`)的敘事調性。

## 收尾

每篇定稿前過 `de-ai-tone`(潤成台灣人講話)+ `journal-preflight-scan`(claim 逐條查證,任一不實即阻斷)。要一次產整包建造日誌社群素材就轉 `release-page`。
