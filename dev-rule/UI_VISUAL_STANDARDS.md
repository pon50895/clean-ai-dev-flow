# UI 視覺與體驗標準 (Visual Standards)

## 1. 核心美學
- **主題 (Theme)**: 絕對使用 **深色模式 (Dark Mode)**。
- **基調**: 深邃星空感、玻璃擬態 (Glassmorphism)、漸變微光。
- **色彩**: 避免純色，使用 Indigo/Purple 漸變。

## 2. 溝通限制 (Communication)
- **NO EMOJI**: 嚴禁在代碼、註釋、系統日誌與回覆中使用任何 Emoji。
- **雙語支持**: 所有 UI 必須考慮中英對照，關鍵合規內容必須支援動態語系切換。

## 3. 交互標準
- **微動畫**: 按鈕與卡片應具備 Subtle Hover 效果。
- **加載體驗**: 長時間操作必須使用 Skeleton Loading 或進度條，禁止出現白屏。
- **強制閱讀**: 法律同意協議必須實施「捲動觸發」機制，確保用戶物理上完成捲動動作。

## 4. 驗收門檻
- **截圖對照**: Phase 完成後必須產出實機截圖報告。
- **跨瀏覽器**: 至少確保在 1200x800 分辨率下無跑版。
